# Tarea 03 - Programación de Dispositivos Móviles

Proyecto realizado para Programación de Dispositivos Móviles.

## Proyecto

Aplicación Android de un cine desarrollada en Android Studio, que muestra una **cartelera de películas** mediante el componente `ListView`.

- **Cartelera:** presenta ocho películas con sus respectivos pósteres, títulos y géneros.
- **Selección:** al pulsar una película, se ejecuta el evento `setOnItemClickListener` y se muestra un mensaje con su nombre.

La interfaz está diseñada con XML y utiliza un adaptador personalizado (`PeliculaAdapter`) para mostrar la información de cada película.

## Lenguaje

Java y XML.
