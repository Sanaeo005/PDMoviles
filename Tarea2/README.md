# Tarea 02 - Programación de Dispositivos Móviles

Proyecto realizado para Programación de Dispositivos Móviles.

## Proyecto

Aplicación Android de un cine desarrollada en Android Studio, que contiene dos interfaces gráficas:

- **Cartelera:** muestra tres películas con sus respectivos pósteres y permite seleccionar una de ellas.
- **Compra de boletos:** contiene un formulario para introducir el nombre del cliente, elegir horario y tipo de boleto, y seleccionar complementos.

Ambas interfaces están diseñadas con XML y se visualizan de manera independiente.

## Lenguaje

Java y XML.
